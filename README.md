# 자바 개발자의 AI 전환 시리즈 Vol.1 — AI를 위한 수학

자바 개발자가 AI/ML 분야로 전환할 때 필요한 수학적 기초를 다루는 책입니다.

## 특징

- **Java First**: 모든 개념을 Java로 먼저 구현
- **시각화**: 기하학적 의미를 그래프로 이해
- **AI 연결**: 각 개념이 실제 AI에서 어떻게 쓰이는지 연결

## 목차

0. 오리엔테이션
1. 스칼라, 벡터, 행렬 — 데이터의 그릇
2. 벡터 연산 — AI의 기본 동작
3. 행렬 연산 — 데이터 변환의 핵심
4. 함수와 그래프 — 입력과 출력의 관계
5. 미분 — 변화를 측정하다
6. 경사하강법 — AI 학습의 엔진
7. 손실 함수 — 틀린 정도를 측정하다
8. 실전: 손글씨 분류기 구현
